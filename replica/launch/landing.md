## 3. How it works

1. **Write a line.** Start with `harvest()`. That's real Python.
2. **Press Run and watch.** Your drone does exactly what you wrote, and the line it's on lights up.
3. **Earn the next idea.** Harvests buy loops, functions and lists. Each comes with a page in the field guide that explains it.

## 6. FAQ

- **Do I need to know how to code?** No. You start with one line, and every new idea comes with a page that explains it.
- **Is it real Python?** It's a small, real subset: variables, `if`, loops, functions, lists, dicts. What you learn carries over to Python. Some things aren't in yet, like classes, and the game tells you so instead of failing silently.
- **What if I get stuck?** Errors point at the line and say what's wrong. Lessons with hints are in development; until then, every idea has an explained example in the field guide.
- **Will I lose my code?** It saves as you play, keeps a copy when you close the tab, and can be backed up to the cloud with an email sign-in.
- **Does it run on a Mac, a Chromebook or a school laptop?** Yes, in any modern browser.
- **Is there a subscription?** No. The start is free and the rest is $9 once.
- **Can I use it with a class or my kids?** Yes. Classroom, with a teacher view, is coming; join the waitlist.
